# 港口盲箱

离线单人集装箱开箱小游戏。六种颜色的集装箱区分不同售价，货物从完整物品库随机抽取，购买后可逐件刮开、收藏或出售。

## 运行游戏

直接用浏览器打开 `outputs/港口盲箱.html`。这是包含图片、样式和脚本的离线成品，无需安装依赖。进度保存在当前浏览器的本地存储中。

也可以在项目根目录运行：

```sh
node work/serve.cjs
```

打开终端输出的本地网址，使用拆分的网页文件运行游戏。

## 当前规则

- 共491件物品，资料按10个分类归档，所有集装箱从同一完整物品库随机抽取。
- 物品价值固定使用用户截图标价，开箱时不重新分配价格。
- 物品品级以颜色区分，页面不显示品级名称。
- 按物品自身的宽×高计算占格，背包也计算占格；80张房卡均为1×1。
- 已剔除没有价格的“建筑图纸5号”和用户要求剔除的“破损的脑机”。
- 启动资金暂定3,000,000，六种箱子的售价暂定1,500,000至10,000,000。
- 后续游戏规则仍可调整。

## 目录

| 路径 | 内容 |
|---|---|
| `outputs/港口盲箱.html` | 可直接打开的完整离线游戏 |
| `outputs/harbor-bid/dist/` | 网页源码和图片素材 |
| `outputs/全部物品数据.json` | 491件物品的标价、占格和品级数据 |
| `outputs/全部物品清单.md` | 物品分类总览 |
| `outputs/集装箱图片说明.md` | 集装箱图片素材和生成提示词 |
| `work/` | 数据整理、打包和检查脚本 |

## 打包与检查

在项目根目录运行，需要本机安装Node.js：

```sh
node work/package-game.cjs
node work/check-game-v2.cjs
node work/audit-screenshot-prices.cjs
```

第一条命令根据拆分源码生成离线成品。检查脚本核对物品库、占格、标价、交易结算和存档；价格核对脚本对照本次对话中可核验的295个截图标价。

部分早期数据整理脚本依赖原始截图的本地路径。运行成品、修改网页和重新打包无需这些原始截图。

物品名称及截图来自用户提供的《三角洲行动》资料。集装箱图片以用户提供的图片为参考，经内置imagegen工具制作。素材的第三方权利归其权利人所有。
